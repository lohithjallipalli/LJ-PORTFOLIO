# LJ-PORTFOLIO

A modern, high-performance personal developer portfolio built for **Lohith Jallipalli** to showcase engineering projects, technical skills, and professional milestones.

### Overview
- **Core Stack**: Engineered with React, Vite, and GSAP for fluid animations, custom themes, and responsive design.
- **Featured Projects**: Highlights flagship builds including *LeaveFlow (ServiceNow)*, *Chess Analyzer*, *Sudoku-Assist*, and *PRO-MAN*.
- **Interactive Showcase**: Dynamic skill proficiency cards, filterable career timelines, and detailed project preview modals with live links.
- **Connected Services**: Real-time visitor metrics via Firebase and direct contact form dispatch via EmailJS.
- **Production Architecture**: Optimized build pipeline with modular React components and zero-latency client-side routing.
